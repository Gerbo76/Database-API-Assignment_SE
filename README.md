# Database API Assignment

## Setup

1. Install the dependencies with `pip install -r requirements.txt`.
2. Copy `.env.example` to `.env`.
3. Replace the placeholder values in `.env` with your Supabase project URL
   and API key. Keep `.env` private; it is excluded from Git.
4. Run the application with `python order-entry.py`.

Never commit or share a real Supabase API key. If a key has been exposed,
rotate it in your Supabase project before using it again.
